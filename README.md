# AbdurRahman Almqdashi — Portfolio

A responsive, single-page portfolio for AbdurRahman Almqdashi, full-stack software engineer and AI application developer.

## Run locally

Open `index.html` in a browser, or serve this directory with any static web server. The site uses plain HTML, CSS, and JavaScript—no build step or package installation is required.

## Publish with GitHub Pages

In the repository settings, open **Pages**, select the `main` branch and `/ (root)` as the publishing source, and save. The site is ready to deploy from the repository root.

## Features

- Responsive layout with mobile navigation
- Accessible landmarks, skip link, focus styles, and reduced-motion support
- Project, skills, learning, and contact sections
- Email copy interaction and dynamic copyright year
- No framework or third-party JavaScript dependencies
